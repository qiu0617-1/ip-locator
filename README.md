# IP 定位仪

一个纯静态的 IP 归属地查询页面，同时会告诉你**你自己**此刻的真实位置。

- 输入任意 IP，查它的国家 / 省州 / 城市 / 运营商 / 坐标 / 时区
- 点「定位我」，走浏览器（Windows / iOS / Android）的定位服务，精确到区县，误差几十米
- 打开就会先看到一页「你正在被识别」，让你直观看到任何网站都能拿到什么

## 链接形式

| 链接 | 打开后 |
| --- | --- |
| `/` | 查本机 IP 归属地 |
| `/#8.8.8.8` | 直接查这个 IP |
| `/#locate` | 直接测设备真实位置 |

## 它不收集任何数据

纯静态页面，没有后端、没有数据库、没有访问日志。
`fetch()` 只发往三个公开的 IP 查询接口和一个地名反查接口，参数是访客自己查的那个 IP 或他那次定位的坐标。
访客看到的是自己的位置，看完即走，不会回传给任何人。

## 关于精度

IP 归属地来自第三方注册信息，通常只到城市，**而且经常是错的**（移动网络和省内汇聚的 IP 尤其容易落到省会）。
页面会把多个数据源的结论做交叉核对，不一致时直接标红告诉你「不可信」。
想知道自己在哪，请用「定位我」，那是设备定位，不是 IP。
